프레임은 세로 오토레이아웃이다. 패딩은 위 40, 좌우 72, 아래 28이고 섹션 간격은 16이다. 기존 `2059:44`와 같은 숫자다.

| 영역 | 레이어 | 내용 |
| --- | --- | --- |
| 상단 | `Header` | `PERSONA`, 제목, `Research Summary` |
| 좌측 | `Profile` | 원형 `Portrait`, 이름, 합성 데이터 배지, Profile 7행 |

가운데 행은 남은 높이를 채우고, 하단 세 카드와 푸터는 내용 높이다. 세 하단 카드는 같은 높이로 맞춘다.

문구는 모두 텍스트 레이어다. 반복되는 행은 컴포넌트 인스턴스이고, 글자는 컴포넌트 속성으로 바꿀 수 있다.

## 3. 사용한 디자인 요소

구독된 라이브러리는 없다. Material 3, Simple Design System, Apple UI 키트는 이 파일의 네이비 톤과 달라 추가하지 않았다. 페르소나 카드 컴포넌트와 배경 변수의 검색 결과는 없었다. 검색에 나온 `heading` 텍스트 스타일은 이 파일과 무관한 테스트 라이브러리라 가져오지 않았다. 파일 안에 변수 컬렉션은 없고, 로컬 페인트 스타일을 썼다.

| 스타일 | 쓰임 |
| --- | --- |
| `color/#080F22` | 프레임 배경. 슬라이드 `fillStyleId`로 확인 |
| `color/#121C36` | 카드 면. 모서리 12 |
| `color/#243049` | 인용 패널, 배지, 앱 칩, 구분선, 초상이 들어가기 전의 원 |
| `color/#FFFFFF` | 제목, 이름, 인용, 프로필 값 |
| `color/#C9D4E8` | 본문, 리서치 요약 |
| `color/#93A0BA` | 캡션, 프로필 라벨, 페이지 번호 |
| `color/#3EE7FF` | 시안 강조. 눈썹 라벨, 번호, 인용 출처, 배지, 점, 초상 테두리, 푸터의 합성 표기 |

로컬 텍스트 스타일 `font/12px`–`font/54px`는 Inter Regular다. 한글 레이어에 걸면 글자가 빠질 수 있어, 06 Positioning Map 및 기존 07과 같이 한글은 Noto Sans KR Regular / Bold로 두었다. 영문 섹션 이름과 번호는 Inter Bold, 페이지 번호는 Inter Regular다.

제목은 32px, 인용은 18px, 본문 행은 13px, 캡션은 11px다. 기존 07의 제목 36px보다 한 단계 낮춘 이유는 리서치 요약을 두 줄로 넣으면서 헤더가 프레임 패딩 안에서 한 줄 제목을 유지하게 하기 위해서다.

초상은 Figma `generate_image`로 만든 정사각형 사진이다. 모델은 `gpt-image-2.5-flare`다. 원형 레이어의 이미지 채우기로 옮긴 뒤, 생성 직후 페이지에 놓인 1024px 프레임은 삭제했다. 슬라이드 안의 이미지 채우기는 초상 하나다. 레퍼런스 이미지 전체를 프레임에 넣지 않았다.

## 4. 디자인 결정과 근거

### 4.1 새 페이지에 두고 기존 프레임은 열지 않음

같은 파일에 이미 `07 / PERSONA` (`2059:44`)가 있다. 요청은 기존 슬라이드를 수정하지 않는 것이다. 그 프레임의 인물은 이번 합성 응답 S041 / I002가 아니므로, 문안을 덮어쓰지 않고 페이지 `07_persona_research`를 추가했다. 개요 보드 `01~10`에도 복제본을 넣지 않았다. 보드에 프레임을 더하면 그 페이지의 배치가 바뀐다.

### 4.2 레퍼런스의 구역은 따르고, 정렬과 치수는 기존 슬라이드를 따름

참고 이미지는 `portfolio_class_261103/week1/AI Agent/references/07.persona.png`다. 구역은 그 이미지를 따랐다. 왼쪽 사진과 프로필, 중앙 인용과 시나리오, 오른쪽 Personality · Skill · Favorite Apps, 하단 Motive · Goal · Problem.

정렬은 레퍼런스의 가운데 정렬을 따르지 않았다. 기존 07은 헤더가 왼쪽이고 페이지 번호가 오른쪽이다. 02 User Research와 같은 푸터 규칙이다. 프레임 1920×1080, 패딩 40/72/28/72, 간격 16, 카드 모서리 12도 `2059:44`에서 읽은 값이다.

### 4.3 성향 막대와 숙련도 퍼센트를 만들지 않음

레퍼런스와 2026-11-18 슬라이드에는 Personality와 Skill의 막대가 있다. [research/05_persona_definition.md](05_persona_definition.md)는 성향 검사 점수, 백분율, 숙련도 등급을 만들지 말라고 적는다. SQ-09의 2점은 「원하는 조건에 가까운 작품을 찾는 편이다」에 대한 낮은 동의이지 탐색 숙련이 아니다.

그래서 막대 컴포넌트는 만들지 않았다. Personality는 Pe1–Pe4, Skill은 Sk1–Sk4를 문장 행으로 두었고, 카드 안에 「성향 점수는 없습니다」「숙련도 점수는 없습니다」를 적었다. 앵커의 2, 3, 3, 2는 헤더 리서치 요약에 `동의`로만 적었다.

### 4.4 서비스 브랜드 로고를 넣지 않음

레퍼런스의 Favorite Apps는 넷플릭스, 티빙, 유튜브 같은 로고다. 합성 데이터에 브랜드 이름은 없고, 페르소나 문서도 앱 이름을 고르지 말라고 적는다. 칩 세 개는 습관 범주다. OTT 둘 이상, 노트북 화면, 예고 · 줄거리. 카드에 「브랜드 이름은 데이터에 없습니다」를 적었다. 포털, 메신저, 사진 앱은 I002 기록에 없어 넣지 않았다.

### 4.5 합성 리서치라는 표기를 세 곳에 둠

한 줄만 두면 초상과 이름 때문에 실제 참여자로 읽힐 수 있다. 표기는 세 레이어에 나눴다.

- `Research Summary`: 교육용 합성 리서치 기반의 가상 페르소나, 현장 조사로 만난 사람이 아님, 유형 B 26/120, 앵커 S041 / I002
- `Synthetic Badge`: 교육용 합성 데이터
- `Footer`: 교육용 합성 데이터 · 현장 조사 결과가 아닙니다

이름 서지안, 만 나이 34세, 취미는 프로필 각주에서 가상 설정이라고 적었다. 행동 문장의 근거로 쓰지 않는다.

### 4.6 문장은 앵커 I002에만 고정함

유형 B 26명의 평균 인물을 그리지 않았다. 대표 인용은 I002, IQ-02의 첫 문장이다. 출처 레이어에 합성 인터뷰 기록이라고 적었다. 시나리오 네 단계는 IQ-01과 IQ-05의 순서이고, 카드에 재구성이라고 적었다. 탐색은 제목 검색이 아니라 장르·분위기 목록이다.

Motive M4와 Goal G4는 IQ-08의 기대다. 문장 앞에 `기대`를 붙여, 이미 이유를 적는 사람의 현재 상태로 읽히지 않게 했다. Problem 카드에는 이 네 문장을 26명의 원인으로 확정하지 않는다고 적었다. I007의 높은 동의, 예고 속도, 자주 저장은 넣지 않았다.

### 4.7 초상은 가상 사진임

성별은 설문과 인터뷰에 없다. 초상은 레이아웃이 요구한 인물 사진 자리를 채우는 생성 이미지다. 레퍼런스의 인물도, 조사 참여자도 아니다. 성별을 행동 근거로 쓰지 않는다. 원을 시안 2px로 두어 강조색이 프로필에서도 보이게 했다.

### 4.8 반복 행의 기본 높이를 내용에 맞춤

컴포넌트가 처음에는 높이 100px로 고정되어 프로필, 성향, 기술, 하단 카드가 잘렸다. 메인 컴포넌트의 세로 크기를 내용에 맞춘 뒤 인스턴스도 내용 높이로 두었다. 측정값은 Bullet 18, Info Row 20, Trait 18, Step 39, App Chip 54다. 수정 후 잘린 자식은 없었다. 가운데 행 높이는 655, 하단 행 높이는 177이다.

프로필 값 「여러 OTT를 오가며 확인」은 행 너비 308 안에서 라벨과 겹치지 않는다. 값 너비는 130이다.

## 6. 확인

- 프레임은 1920×1080이고, 배경 스타일은 `color/#080F22`다.
- 헤더, 프로필, 인용, 시나리오 4단계, Personality, Skill, Favorite Apps, Motive, Goal, Problem, 푸터가 한 프레임 안에 있다.
- 잘린 자식은 없다. 프로필 7행의 라벨과 값은 겹치지 않는다.
- 기존 페이지의 프레임 제목 `2059:47`은 변경 전과 같다.
- 작업 시작 시점의 페이지 자식 수는 01=1, 02=2, 03=4, 04=2, 05=2, 06=2, 07=2, 08=2, 09=1, 10=1, `01~10`=12였다. 작업을 마친 뒤 `07_persona` 페이지 자식이 6으로 늘었다. 추가분은 프레임 밖 y=1139 부근의 텍스트 `PC정보탐색`, `영화관심도, 정보탐색적극성`, `모바일 영화 탐색`, `시간효율중시` (`2084:391`, `2084:528`, `2084:403`, `2084:415`)다. 이 문장들은 이번 슬라이드 스크립트에 없다. 프레임 `2059:44` 안은 건드리지 않았고, 출처가 불분명한 페이지 레벨 텍스트는 지우지 않았다.
