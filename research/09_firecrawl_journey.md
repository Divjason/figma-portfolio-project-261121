# MoviePick 리서치 문서 09 — Firecrawl 여정 콘텐츠

- 프로젝트: MoviePick
- 역할: UX Content & Information Architecture Analyst
- 단계: 리서치 문서 09. 사용자 여정 화면의 콘텐츠와 기능
- 작성일: 2026-11-21
- 상태: 공개 화면 추출 완료. 로그인 후 저장 화면은 미추출
- 서비스: https://moviepick-web.vercel.app/
- 기준 화면 기록: [research/08_playwright_journey.md](08_playwright_journey.md)
- 도구: Firecrawl MCP `firecrawl_map`, `firecrawl_scrape`
- 이전 문서: 수정하지 않음

이 문서는 Firecrawl이 렌더한 문구, 제목, 입력의 value, 버튼 이름, HTTP 상태만 적는다. 네트워크 응답 본문, 스크롤 좌표, 저장소 키는 이번 호출에서 읽지 않았다. 문서 07의 가설과 문서 08의 문장은 바꾸지 않는다.

## 1. 문장을 구분하는 규칙

| 표기 | 의미 |
| --- | --- |
| 화면에서 확인 | 렌더된 Markdown 또는 페이지 DOM에서 읽은 문구, 제목, 입력값, 버튼 |
| 주소에서 확인 | `firecrawl_map`의 URL 목록, 또는 지정한 주소의 HTTP 상태와 제목 |
| 미추출 | 이번 호출에서 조작하지 않아 화면에 없었거나, 응답 본문·좌표·저장소처럼 도구가 돌려주지 않은 항목 |
| 한계 | 로그인 세션이나 별도 문서 주소가 없어 저장 완료 화면을 열지 못한 범위 |

## 3. 주소 구조

검색, 상세, 즐겨찾기는 홈과 다른 문서 주소로 열리지 않았다.

| 주소 | HTTP | 제목 | 구분 |
| --- | --- | --- | --- |
| `/` | 200 | MoviePick | 주소에서 확인. 홈, 검색 결과, 상세 블록, 즐겨찾기 구역이 이 주소에 함께 있다 |
| `/movies/496243` | 404 | 404: NOT_FOUND | 주소에서 확인. Vercel 문구 `This page doesn’t exist` |
| `/favorites` | 404 | 404: NOT_FOUND | 주소에서 확인. 같은 Vercel 404 |
| 그 외 경로 | — | — | 미추출. 사이트 맵에 루트 이외의 URL이 없었다 |

페이지 안 `<a>`는 홈 컨트롤 목록에 없었다. `nav`는 0개다. `form`은 2개이며, 하나는 영화 검색, 하나는 장소 검색이다.

## 5. 영화 검색

검색 컨트롤은 `영화 찾기` 제목 아래에 있다.

| 항목 | 값 | 구분 |
| --- | --- | --- |
| 입력 placeholder | `예: 기생충, 인셉션` | 화면에서 확인 |
| 첫 화면 value | 빈 문자열 | 화면에서 확인 |
| aria-label | 빈 값 | 화면에서 확인 |
| form | 영화 검색 form 안. 컨트롤은 이 입력과 버튼 `검색` | 화면에서 확인 |
| 버튼 | `검색` | 화면에서 확인 |
| 검색이 만드는 주소 | 입력 뒤에도 `https://moviepick-web.vercel.app/` | 화면에서 확인 |
| 장르·분위기·필터·정렬 | 컨트롤 목록에 없음 | 화면에서 확인 |

`드라마`를 넣고 `검색`을 누른 뒤 입력 value는 `드라마`로 남아 있었다. `기생충` 검색 뒤의 입력 value는 읽지 않았다.

### 6.3 맞지 않는 문자열

`zzzznotamovie999`를 넣고 `검색`을 눌렀다. 상태 문구는 `검색 완료`다. 영화 `h3`는 0개다. `영화 찾기` 구역의 텍스트는 `영화 찾기 검색`이다. `결과가 없습니다`는 이 렌더에 없다.

## 7. 영화 상세

`기생충` 카드의 `상세`를 눌렀다. 주소는 `/`로 남았다. 상세는 결과 카드 4장 아래, `내 즐겨찾기 (0)` 위에 `h2`로 붙었다. 이 블록의 iframe은 0개, video는 0개다.

| 순서 | 콘텐츠 | 구분 |
| --- | --- | --- |
| 제목 | `기생충` | 화면에서 확인 |
| 본문 | 라벨 없는 줄거리 한 단락. 첫 구절은 `가족 모두가 일자리를 구하지 못해…`, 끝은 `드러내는데...` | 화면에서 확인 |
| 메타 | `개봉일: 2019-05-30 / 평점: 8.5` | 화면에서 확인 |
| 동작 | `상세 닫기` | 화면에서 확인. 닫기 버튼은 누르지 않음 |
| 같은 클릭의 상태 문구 | `영화 상세는 표시되지만 클릭 저장 실패: MySQL 저장 실패: 2005 (HY000): Unknown MySQL server host 'mysql-35c1ab15-tcocs-f176.j.aivencloud.com' (-2)` | 화면에서 확인 |

상세 블록을 연 뒤 페이지 텍스트에서 찾은 단어는 `개봉`과 `평점`이다. `장르`, `러닝`, `예고`, `감독`, `출연`, `유사`, `줄거리`, `태그라인`은 그 텍스트에 없다. 상세 `h2` 구간에 포스터 이미지 Markdown은 없다. 저장 버튼은 카드에 있고, 상세 구간의 버튼 이름은 `상세 닫기`다.

상세 HTTP 본문, 장르 이름, 러닝타임 숫자, 블록의 뷰포트 좌표는 미추출이다. `오디세이` 상세와 `상세 닫기` 이후 상태도 미추출이다.

## 9. 여정에서 정보가 부족하거나 불명확한 부분

아래는 이번 렌더에 있던 문구로 판단한 빈칸이다. 문서 07의 가설을 요구사항으로 바꾼 것이 아니다.

| 여정 단계 | 화면에서 확인한 정보 | 부족하거나 불명확한 점 |
| --- | --- | --- |
| 영화 탐색 | 상태 `인기 영화를 살펴보세요.` 카드 19장. 검색 placeholder는 제목 예시 | 장르, 분위기, 필터, 정렬이 없다. 목록이 인기순이라는 정렬 이름은 없다. 날짜 옆의 `0.0`이 무엇을 뜻하는지는 카드에 없다. `0.0`은 2026-12-16 같은 날짜와 1997-08-23 같은 날짜에 함께 나온다 |
| 검색 | 한 개의 검색 입력과 `검색` | 입력 라벨이 없다. placeholder만 제목 예시다. 제목, 인물, 개요 중 무엇을 찾는지 화면이 적지 않는다 |
| 검색 결과 | 카드의 포스터, 제목, 점수, 날짜, `상세`, `♡ 저장` | 상태 문구는 4건, 20건, 0건이 모두 `검색 완료`다. 건수와 빈 결과 안내가 없다. 20장 뒤에 페이지 이동이 없다. `우리가 계절이라면`, `한 여름의 꿈`, `슬로우`가 나온 이유가 없다. 일부 카드는 점수·날짜 자리에 `포스터 없음` 또는 `개봉일 미정`만 있다 |
| 상세 | 제목, 라벨 없는 줄거리, `개봉일`, `평점`, `상세 닫기` | 장르, 러닝타임, 예고, 감독, 출연, 유사 작품이 블록에 없다. 별도 주소가 없고 `/movies/496243`은 404다. 같은 클릭이 상태 칸을 MySQL 호스트 오류로 바꾼다. 상세가 보인다는 문장과 저장 실패 문장이 한 줄에 있다 |
| 관심 영화 저장 | 카드의 `♡ 저장`. 로그아웃이면 로그인 요청. 즐겨찾기는 `(0)`과 안내 문장 | 저장 성공 목록, 저장한 제목, 이유 입력, 상세 안의 저장이 이 화면에 없다. 로그인 후 화면은 한계 |

영화관 검색 결과와 통계 새로고침 뒤의 목록도 미추출이다. 두 구역은 홈에 보이지만, 버튼을 누르기 전의 문구만 확인했다.
