# MoviePick STEP 01 — UX 리서치 계획

- 프로젝트: MoviePick
- 역할: UX Researcher
- 단계: STEP 01. 페르소나 제작을 위한 탐색 리서치 설계
- 작성일: 2026-11-21
- 상태: 설계 완료 (수집 전)

## 1. 작업 목적

MoviePick은 영화 검색, 상세 정보 확인, 관심 영화 저장을 제공한다. 현재 사용자 리서치 자료와 이용 로그가 없으므로, 페르소나를 추정으로 만들지 않고 탐색 행동과 경험의 분포를 먼저 측정하는 조사 계획을 수립한다.

이 문서의 목적은 다음 세 가지다.

1. 페르소나에 들어갈 항목을 채울 리서치 목적을 고정한다.
2. 영화 탐색 행동과 경험 수준을 비교할 설문 12문항을 설계한다.
3. 행동의 이유와 상황을 들을 심층 인터뷰 8질문을 설계하고, 각 질문을 페르소나 항목에 연결한다.

이번 단계의 산출물은 조사 설계다. 응답 수집, 코딩, 페르소나 문장화는 이후 단계에서 진행한다.

## 2. 리서치 목적

| ID | 리서치 목적 | 페르소나에 채울 항목 | 주 방법 |
| --- | --- | --- | --- |
| RO-01 | 누가, 어떤 상황에서, 어떤 경로로 볼 영화를 찾는지 파악한다. | 기본 프로필, 이용 맥락, 탐색 행동 | 설문 SQ-01–SQ-04, 인터뷰 IQ-01 |
| RO-02 | 선택을 가르는 기준, 확인하는 정보, 관심 영화를 남기는 이유를 파악한다. | 목표, 의사결정 기준, 정보 니즈, 저장 동기 | 설문 SQ-05–SQ-08, 인터뷰 IQ-02–IQ-05 |
| RO-03 | 탐색, 정보 확인, 저장 이후 재접근, 선택 확신의 수준을 비교하고, 쉬운 지점과 예상과 다른 지점의 맥락을 수집한다. | 경험 평가, 마찰과 기대, 대표 시나리오 | 설문 SQ-09–SQ-12, 인터뷰 IQ-06–IQ-08 |

세 목적은 검색, 상세, 저장이라는 제품 범위 안에 둔다. 추천 알고리즘 선호도나 결제 의사처럼 현재 기능 밖의 주제는 이번 조사에서 다루지 않는다.

## 3. 페르소나 항목

질문과 연결할 항목을 조사 전에 고정한다. 통증이나 기능 결함을 항목의 기본값으로 두지 않는다.

| 항목 | 정의 |
| --- | --- |
| 기본 프로필 | 영화를 직접 찾아 보는 빈도와 주 사용 기기 |
| 이용 맥락 | 영화를 고르는 대표 상황과 동반 여부 |
| 목표 | 그 상황에서 영화를 찾으며 이루려는 것 |
| 탐색 행동 | 검색, 둘러보기, 목록, 저장된 목록, 주변 추천 중 시작 방식 |
| 의사결정 기준 | 후보를 비교할 때 우선하는 조건 |
| 정보 니즈 | 결정 전에 확인하는 상세 정보 |
| 저장 동기 | 관심 영화를 남기는 빈도, 목적, 남기지 않는 경우의 대안 |
| 경험 평가 | 탐색 용이성, 정보 충분성, 저장 영화 재접근, 선택 확신 |
| 마찰과 기대 | 인터뷰에서 확인되는 잘 된 순간과 예상과 다른 순간 |
| 대표 시나리오 | 검색, 상세 확인, 저장이 한 흐름으로 이어지는 하루의 사용 이야기 |

## 4. 설계 결과

### 4.1 조사 대상과 방법

- 대상: 최근 3개월 안에 볼 영화를 직접 찾아 본 사람. MoviePick 가입이나 특정 앱 사용은 조건으로 두지 않는다.
- 설문: 탐색 행동과 경험 수준의 분포를 본다. 객관식 8문항, 5점 척도 4문항.
- 인터뷰: 설문에서 갈라진 행동 유형을 고르게 포함해, 선택과 저장의 이유를 듣는다. 개방형 8질문.
- 척도 앵커: 1 전혀 아니다, 2 아니다, 3 보통이다, 4 그렇다, 5 매우 그렇다.
- 복수 선택: 최대 3개. 우선순위가 한 응답에 과도하게 섞이지 않게 한다.

### 4.3 심층 인터뷰 질문표

인터뷰는 개방형으로 진행한다. 특정 기능이 부족하거나 특정 불편이 있다고 전제하는 표현은 쓰지 않는다. “있다면”으로 경험의 유무를 응답자에게 맡긴다.

| ID | 질문 | 연결 목적 | 연결 페르소나 항목 |
| --- | --- | --- | --- |
| IQ-01 | 가장 최근에 볼 영화를 고른 과정을 시간 순서대로 이야기해 주세요. 무엇을 보고 싶었고, 어디서 무엇을 확인했나요? | RO-01 | 탐색 행동, 이용 맥락, 대표 시나리오. 실제 순서에서 검색, 상세 확인, 저장이 어디에 놓이는지 확인한다. |
| IQ-02 | 그때 영화를 고르면서 이루고 싶었던 것은 무엇이었나요? | RO-02 | 목표. 장르 선호와 별도로, 휴식, 동반, 안전한 선택, 새로운 시도 같은 목표를 적는다. |
| IQ-03 | 영화를 비교할 때 유독 오래 보거나 꼭 확인하는 정보는 무엇인가요? 그 정보가 중요한 이유도 들려 주세요. | RO-02 | 의사결정 기준, 정보 니즈. 설문에서 고른 기준이 어떤 판단에 쓰이는지 이유와 함께 붙인다. |
| IQ-04 | 관심 있는 영화를 남겨 두는 방식이 있다면 어떻게 하고, 어떤 순간에 그렇게 하나요? 따로 남기지 않는다면 그때의 흐름도 알려 주세요. | RO-02 | 저장 동기. 제품 저장 기능을 전제하지 않고, 저장·메모·미저장을 모두 수집한다. |
| IQ-05 | 남겨 둔 영화를 나중에 다시 꺼내 보는 일이 있다면, 그때 어떤 순서로 무엇을 확인하나요? | RO-02, RO-03 | 저장 동기, 대표 시나리오. 저장이 다시 탐색과 상세 확인으로 이어지는 조건을 듣는다. |
| IQ-06 | 영화를 찾는 과정에서 잘 되었다고 느낀 순간과, 예상과 달랐다고 느낀 순간이 있다면 각각 이야기해 주세요. | RO-03 | 마찰과 기대. 긍정과 불일치를 함께 물어 특정 문제를 유도하지 않는다. 불일치는 있을 때만 페르소나의 마찰로 기록한다. |
| IQ-07 | 지금 사용하는 방법이나 서비스를 계속 쓰는 이유는 무엇인가요? | RO-03 | 마찰과 기대, 탐색 행동. 현재 방식이 유지되는 가치를 기대 항목으로 적는다. |
| IQ-08 | 영화 검색, 상세 정보 확인, 관심 영화 저장을 한곳에서 이어서 할 수 있다면, 어떤 날에 어떻게 쓰게 될 것 같나요? | RO-01, RO-03 | 대표 시나리오, 목표, 기대. MoviePick의 세 기능을 한 사용 이야기로 묶어 페르소나 시나리오의 초안을 만든다. |

진행 메모: IQ-01의 답에서 이미 다룬 내용은 IQ-04와 IQ-05에서 반복해 묻지 않고, “조금 전 이야기에서 저장은 어디에 있었나요?”처럼 이어서 확인한다. IQ-08은 마지막에 두어, 앞선 실제 경험과 구분되는 예상 사용으로 기록한다.

### 4.4 분석 목적

수집 후 분석은 페르소나 항목을 채우는 데 한정한다. 점수만으로 불편의 원인을 단정하지 않는다.

| ID | 분석 목적 | 사용할 자료 | 페르소나에 남길 결과 |
| --- | --- | --- | --- |
| AP-01 | 탐색 빈도, 기기, 상황, 시작 행동을 교차해 행동 유형의 후보를 나눈다. | SQ-01–SQ-04, IQ-01 | 유형별 기본 프로필, 이용 맥락, 탐색 행동 |
| AP-02 | 선택 기준, 확인 정보, 저장 빈도와 저장 이유를 유형에 붙여 니즈를 문장으로 정리한다. 비저장은 결측이 아니라 하나의 유형으로 유지한다. | SQ-05–SQ-08, IQ-02–IQ-05 | 목표, 의사결정 기준, 정보 니즈, 저장 동기 |
| AP-03 | 네 가지 5점 항목의 분포를 비교한다. 평균이 낮은 항목은 원인으로 쓰지 않고, 인터뷰의 잘 된 순간과 예상과 다른 순간으로만 해석을 보강한다. | SQ-09–SQ-12, IQ-06–IQ-08 | 경험 평가, 마찰과 기대, 대표 시나리오 |

분석 순서: AP-01로 유형을 나누고, AP-02로 각 유형의 목표와 저장 이유를 채운 다음, AP-03으로 경험 평가와 시나리오를 더한다. 한 유형을 뒷받침하는 설문 패턴과 인터뷰 인용이 둘 다 있을 때만 페르소나 문장으로 확정한다.

## 5. 주요 결정 사항

1. 조사 대상을 MoviePick 사용자로 한정하지 않았다. 서비스 이용 자료가 없고, 페르소나는 영화 탐색 경험에서 만들기 때문이다.
2. 리서치 목적을 세 개로 제한했다. 탐색 경로, 선택·저장 이유, 경험 수준의 순서로 페르소나 항목과 대응시킨다.
3. 설문은 객관식 8개와 5점 척도 4개만 사용했다. 개방형 이유는 인터뷰로 넘겨 설문에서는 비교 가능한 분포를 얻는다.
4. 불편을 전제하는 문항을 넣지 않았다. 척도는 “어렵다”의 원인을 지목하지 않고 용이성, 충분성, 재접근, 확신을 각각 긍정 문장으로 묻는다.
5. 저장하지 않는 응답을 유지했다. SQ-08에 “저장하지 않는다”를 두고, SQ-11에는 “해당 없음”을 두어 비저장 사용자를 저장 경험 문항에 끌어들이지 않는다.
6. 복수 선택은 최대 3개로 제한했다. 기준과 정보의 우선 묶음을 페르소나에 쓰기 위해서다.
7. 인터뷰 IQ-06은 잘 된 순간과 예상과 다른 순간을 함께 묻는다. 불일치만 물으면 마찰이 있는 사용자로 응답이 기울기 때문이다.
8. 질문 ID는 설문 `SQ-01`–`SQ-12`, 인터뷰 `IQ-01`–`IQ-08`, 목적 `RO-01`–`RO-03`, 분석 `AP-01`–`AP-03`으로 고정해 이후 페르소나 근거의 출처로 쓴다.

## 6. 이번 단계에서 하지 않은 일

- 응답 수집과 코딩
- 페르소나 프로필 작성
- 화면 요구사항이나 기능 우선순위 도출

다음은 이 문항으로 설문을 배포하고, 행동 유형이 갈리는 응답자를 인터뷰한 뒤 AP-01–AP-03 순서로 페르소나 항목을 채우는 단계다.
